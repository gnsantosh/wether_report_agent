ADK 2.0 Architecture Notes

📐 Graph Execution Model

In ADK 2.0 the Agent is a node in a workflow graph. Tool calls are edges to child nodes. The LLM decides routing dynamically — no static edges needed for single-agent setups.

⚡ Parallel Tool Calls

For compound queries (e.g. "weather + AQI in Delhi"), ADK 2.x resolves tool call unions in parallel, reducing total latency significantly.

🔄 Automatic Retries & Exception Handling

ADK 2.0 has native automatic retries. Tool functions use narrow except (KeyError, TypeError, ValueError) clauses so unexpected errors propagate up to the framework's retry handler instead of being silently swallowed.
